<h1 align="center">wqq-float · 微趣趣线报网桌面悬浮通知</h1>

<p align="center">微趣趣线报网（bbs.weiququ.cn）的 Windows 桌面常驻小工具：<b>悬浮球 + 通知条</b>，论坛有新线报时秒级弹出提醒，点一下就能打开帖子。</p>

---

## 下载安装

1. 到 [**Releases**](https://github.com/sverhesgsfdshfveh-source/dz-wqq-float/releases/latest) 下载最新版 `wqq-float.exe`
2. 放到任意位置（建议桌面或单独文件夹，**不要放 `C:\Program Files`** —— 那里没有写入权限，自动更新会失败）
3. 双击运行。首次运行若出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」即可（程序未购买代码签名证书，属正常提示）
4. 若双击没反应，请先安装微软 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)（Win11 与新版 Win10 已内置）

## 功能

- **新帖秒级提醒**：论坛有新线报时，通知条滚动显示标题并播放提示音（默认每 5 秒检查一次，可调 3~300 秒）
- **悬浮球 + 通知条**：常驻桌面置顶；球和条以外的区域鼠标可直接穿透，不挡其他窗口操作
- **点击直达**：单击球打开论坛，单击条打开当前帖子
- **悬停看摘要**：鼠标移到通知条上展开卡片，显示作者 / 版块 / 时间 / 回复数 / 内容摘要，底部可「打开原帖 ↗」
- **拖动与吸附**：按住球拖动移动位置，位置自动记忆；拖到屏幕右缘自动吸附
- **右键菜单**：球右键 → 打开论坛 / 设置 / 退出
- **托盘常驻**：托盘图标菜单 → 打开论坛 / 设置 / 开机自启 / 退出
- **主题**：纯黑（默认）/ 跟随系统（深色、浅色自动适配）
- **开机自启**：设置页一键开关
- **自动更新**：设置页「检查更新」→ 一键下载安装新版本，自动重启，不用手动替换文件
- **轻量绿色**：单文件、免安装，卸载 = 删除 exe（记得先在设置里关掉开机自启）

## 设置说明

右键悬浮球 → 设置（或托盘菜单 → 设置）：

| 项 | 说明 |
|---|---|
| 论坛地址 | 默认 `https://bbs.weiququ.cn` |
| 数据源 | 微趣趣增强（秒级，推荐）/ 普通 DZ 论坛 RSS（分钟级，连接异常时自动兜底） |
| 主题 | 纯黑 / 跟随系统 |
| 轮询间隔 | 3~300 秒，默认 5 秒 |
| 开机自启 | 勾选后开机自动运行 |
| 检查更新 | 检测新版本并一键升级 |

点「保存」后设置窗会自动关闭，新设置立即生效。

## 自动更新说明

- 只在点击「检查更新」时才会联网检查（读取本仓库 Releases），不会后台偷偷更新
- 发现新版本 → 点「立即更新」→ 自动下载 → 自动替换旧程序 → 自动重启到新版本
- 若网络访问 GitHub 不畅，可手动到 [Releases](https://github.com/sverhesgsfdshfveh-source/dz-wqq-float/releases) 页面下载最新 `wqq-float.exe` 覆盖原文件即可

## 常见问题

**提示「Windows 已保护你的电脑」？**
程序未购买代码签名证书，点「更多信息」→「仍要运行」即可。

**双击没反应 / 界面空白？**
先安装微软 WebView2 Runtime 再试。

**收不到新帖提醒？**
- 检查网络与论坛地址是否可访问；
- 悬浮球出现**橙色警示圈**表示连接异常，程序会自动重试，并把数据源切换到 RSS 兜底通道；
- 打开「设置」可以看到「当前通道」的实时状态。

**数据与隐私**
程序仅从论坛公开接口读取帖子标题等公开信息，不上传任何个人数据；配置只保存在本机（`%APPDATA%\cn.weiququ.float\config.json`）。

## 从源码构建（开发者）

技术栈：Tauri 2 + Rust + 纯静态 HTML/CSS/JS（`ui/`，零构建链）+ WebView2。

```bash
cd src-tauri
cargo test                   # 单元测试
cargo build --release        # 产物：target/release/wqq-float.exe
```

- 前端资源在编译期嵌入 exe，**改前端后同样需要重新 `cargo build`**
- 发布：打 tag（`v*`，需与 `src-tauri/Cargo.toml` 的版本号一致）推送后，
  GitHub Actions 会自动跑测试、构建并创建 Release 上传 exe
