# wqq-float 桌面悬浮通知工具 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 bbs.weiququ.cn 构建 Windows 桌面常驻「悬浮球+长条」新帖通知客户端（Tauri 2 单 exe），配套服务端只读 JSON 接口。

**Architecture:** 两部分——服务端在 DiscuzX5 仓库新增 `wqq_notifier.php`（水位式只读 JSON，查询模式照抄已验证的 wqq_live.php）；客户端 wqq-float（Tauri 2 + Rust + 纯静态前端，无 Node 构建链），恒定尺寸透明窗口 + Windows 像素穿透 + 全 CSS 动效，Rust 侧 tokio 轮询（WqqApiSource 秒级 / RssSource 通用 DZ 兜底）。

**Tech Stack:** Rust（tauri 2、tauri-plugin-opener/autostart/single-instance、reqwest+rustls、tokio、serde、quick-xml、anyhow）；前端 HTML/CSS/JS 零依赖零构建；PHP 8.2（服务端，复用 Discuz 内核）。

**Spec:** `wqq-float/docs/superpowers/specs/2026-10-16-wqq-float-design.md`

## Global Constraints

- 生产站点铁律：服务器上只新增 `/site/discuz/web/wqq_notifier.php`，不动任何现有文件；部署走 README §5.1 流程（scp → 验证 → commit）；验证一律 `ssh dz-server "curl -s -H 'Host: bbs.weiququ.cn' http://127.0.0.1:8080/..."`；临时文件只放 `/site/discuz/tmp_backup/`
- 凭据（README 第三节）绝不写入任何会推送的文件
- 客户端无 Node/npm：`frontendDist` 指向 `ui/` 静态目录，CLI 用 `cargo tauri`
- reqwest 用 rustls-tls（不用默认 schannel：本机已实测 schannel 证书吊销检查会 CRYPT_E_REVOCATION_OFFLINE 断连）
- 前端渲染帖子数据一律 `textContent` 填充，禁止 innerHTML（RSS 源内容不可信，防 XSS）
- Tauri identifier 固定 `cn.weiququ.float`；窗口 label：`float`（悬浮主窗）与 `settings`（设置窗）
- 事件名固定：Rust→JS `new-threads`（`Vec<Thread>`，最新在 `[0]`）、`conn-state`（`{"ok":bool,"via":"wqq"|"rss"}`）
- 轮询间隔默认 5 秒，可配 3~300；连败 3 次退避 30 秒
- 两个仓库分别提交：`DiscuzX5/`（服务端）与 `wqq-float/`（客户端）
- 动画参数：展开卡 250ms `cubic-bezier(.4,0,.2,1)`；长条滚动切换 300ms

## Review Focus

- **非 JSON 错误响应**（503 HTML / 空体）传入解析不 panic，返回 Err 进退避 → Task 4 测试 `parse_notifier_json` 塞 HTML 片段
- **RSS 恶意/复杂内容**：CDATA 内含 HTML 标签、属性转义、rfc822 GMT 时区 → Task 5 fixture 全覆盖，解析后纯文本
- **换论坛/源后旧水位卡死**（新站 tid 小于旧水位 → 永远 changed:0）→ Task 7 测试 `save_settings` 必须重置水位为 0
- **窗口位置越界**（显示器被拔，存的位置不在任何可视区）→ Task 8 启动时 clamp 回主屏
- **RSS 帖子内容 XSS** → 全局约束 textContent；Task 8 手工验证长条/展开卡正常渲染含 HTML 字符的标题

  - `json_encode(..., JSON_UNESCAPED_UNICODE|JSON_UNESCAPED_SLASHES)`
